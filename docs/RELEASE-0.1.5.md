# Subaudi 0.1.5

## 阅读与操作

- 默认连续阅读，页面自然衔接，滚轮滚动；只渲染视野附近的页面。方向左右键逐页，PageUp/PageDown/空格滚屏，Home/End 到首尾。可切换单页模式。
- 工具栏从左到右：目录/书签、跳转返回、页码、缩小/百分比/放大、适配方式、阅读模式、页面工具。Ctrl+滚轮缩放；侧栏展开导致宽度改变时保持当前阅读页。
- 补齐 PDF.js 文字层的缩放参数，修正透明选字区域与实际字形不一致的问题。高亮矩形只取实际文字；重绘完成前不接受新选区坐标。50% 缩放下的跨页高亮已校验边界，导出后重新打开做了视觉检查。
- 选字后右键可解释、复制、高亮、添加批注、另存带批注的 PDF。选字本身不再自动挤开解释侧栏。
- 弹出菜单点外部空白或 Esc 关闭；目录树和左侧分组作为常驻导航，由标题手动折叠。
- PDF 原生目录、内部链接、个人页书签可用。书架、解释记录、高亮与批注分组可折叠。
- 书架和解释记录提供删除入口。删除教材会移除关联解释和批注；删除父解释会同时删除后续解释。不会删除用户导入的原始文件，也不会清空用量账本。

## 高亮、批注与保存

批注自动保存到本地数据库，支持跨页选区、中文、四种颜色、编辑和删除。批注列表可定位原文。PDF 批注可另存为标准 Highlight 注释（含 Unicode Contents），保留原有页面内容与链接；其他阅读器的批注显示方式可能不同。重新读入导出的 PDF 可查看内置批注。文本资料也可高亮，完整备份 JSON 包含批注。

OCR 和人工修订会生成新文档版本；文字未变的来源块保留批注。被修订的文字上的旧批注仍在旧版本，不猜测迁移位置。

## API

支持 OpenAI 兼容 Chat Completions 和 Anthropic Messages 两种协议，提供 DeepSeek、OpenAI、Anthropic 地址预设及自定义 Base URL。模型 ID 由用户填写。兼容接口不接受 response_format 时可以关闭 JSON 模式，响应仍须通过本地 JSON 和内容结构校验。

Base URL 填到版本路径：例如 `https://api.openai.com/v1`、`https://api.anthropic.com/v1`，不包含 `/chat/completions` 或 `/messages`。密钥按基础地址与协议分开加密保存；换地址后需导入相应密钥。请求不跟随重定向。

格式依据：[OpenAI JSON mode](https://developers.openai.com/api/docs/guides/structured-outputs)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)。本次验证使用模拟服务响应；没有用真实供应商账户逐一验证，也不保证任意模型都能输出合格的教学结构。

## 本地限额的实际行为

这是跨任务、跨重启累计的 token 账本，不是金额额度，也不自动按日/月清零。每次发请求前，用输入 UTF-8 字节数加 4096 输出额度保守预留；剩余额度不够则阻止这次请求。取得服务端用量后，以返回的 total_tokens 替换预留量；失败、取消或超时且无法确认用量时保留预留额。

超限不会影响本地阅读、OCR、高亮、批注和查看已有解释。相同请求命中有效缓存不再调用 API，修改预算也不会使缓存失效。提高累计上限后可以继续新请求。

已经发送的请求仍可能被服务商计费；复杂解释的早期步骤也可能已收费，而下一步被预算阻止。本地估算无法保证服务商账单不超过某个金额，请以服务商实际用量为准。

## 验证

- TypeScript 检查与 21 项单元测试通过。
- CSAPP 1121 页真实教材：连续滚动、目录跳转、真实鼠标拖选、右键高亮、侧栏缩放定位、单页/连续切换；当前视野只绘制 3 页。
- 跨页中文批注、重载恢复、标准 PDF 批注对象读回通过。
- 右键解释、预算不足零请求、提高预算重试、预算下降后缓存复用、端点密钥隔离和删除通过。
- 原有 MD/TXT/Office/PDF 导入、三层递归解释、恢复、真实 OCR 与缓存阶段回归通过。

限制：内部目的地按页跳转，尚未精确滚到 PDF destination 的段落坐标；连续阅读只支持当前已加载相邻页面的原生拖选，长距离跨大量未加载页的选区仍受 20 块/6000 字的解释限制；OCR 对公式和多栏的原有识别限制仍在。
