# 0.1.4 阅读交互修复

- PDF 注释链接支持内部目的页和外部 HTTP、HTTPS、mailto 链接；内部跳转可返回。尚未支持 PDF 附件链接和目的地的精确段落缩放参数。
- Ctrl / Command + 滚轮缩放，尽量保持鼠标指向位置；同页重绘保持阅读位置。
- 侧栏展开、缩放重绘后恢复文字选区；工具按钮不再触发选字处理。
- 多位页码在回车或离开输入框后提交，避免逐位跳页。
- 删除 release 中的 0.1.1 和 v0.1.2，保留其他版本。

实测：F:\temp 中的 Computer Systems: A Programmer’s Perspective 第三版，1121 页。独立测试资料目录、禁用云端请求；首次可读约 1.6 秒，目录第 7 页链接跳至第 19 页并返回；真实鼠标拖选、侧栏重绘后的选区、Ctrl 滚轮缩放通过。外部链接调用由测试拦截验证，未自动启动浏览器。18 项单元测试、阅读/OCR/失败重试回归通过。

进一步值得做：可折叠章节目录；长书名的显示名称编辑；正文裁边以提高整页字体大小；连续滚动和跨页选字；准确的公式与多栏 OCR。这些尚未实现，不应以“极简”为由省去读书所必需的导航与定位能力。
