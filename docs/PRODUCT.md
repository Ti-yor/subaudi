# 产品规格：让教材中隐含的知识变得可见

## 1. 真正要解决的问题

同一段文字给专家的信息更多，通常不是因为专家读得更快，而是专家能把压缩的表述连接到已经掌握的定义、例子、论证、背景、用途和限制。初学者读到的只是这些知识的索引，却缺少索引指向的内容。

用户需要一种附着在原文上的教学辅助：识别当前理解链条的断点，在恰当的位置补上必要内容，让读者回到原文后能继续推理。

产品承诺应是“减少第一次阅读时因知识缺口造成的阻塞，并支持逐渐独立阅读”。不能承诺首次阅读即可拥有专家经验，也不能把文字上读懂等同于长期记忆、迁移或实践能力。

优先级：正确与诚实 > 当前疑惑被解决 > 前置知识可达 > 原文联系清楚 > 阅读负担合理 > 速度与成本 > 功能数量。

## 2. 读者模型与成功证据

首次使用可跳过设置。默认中文解释，不根据“学生”推断年级；每个新领域采用保守的入门解释。可用一句话填写“我学过什么 / 想读懂到什么程度”。

内部读者模型记录概念的 `unknown / exposed / self_reported / demonstrated` 状态。看过解释只算 exposed；点击“懂了”只算 self_reported；完成一道相关任务才增加该任务范围内的掌握证据。模型可以出错，读者可随时修改。

知识按领域和语境区分，例如概率中的独立、线性代数中的线性无关不能合并。掌握证据带时间、题目与范围，不能从一道题推断全面掌握。

成功表现：

- 能用自己的话说明原句的意思和在本节中的作用。
- 能补上关键推理或指出证据依据。
- 能识别条件不满足时结论为何失效。
- 能完成一个与原例不同的小任务。
- 关闭解释后能继续阅读原文，逐渐减少对同类解释的依赖。

## 3. 极简阅读体验

桌面默认一个主阅读区、一条可收起的目录、一侧解释面板。工具栏只保留打开文件、目录、搜索、显示设置、补充开关和设置入口。成本、解析状态、来源等只在相关位置出现。

原文与补充明确区分，不悄悄改写作者文字。原文批注标记应稀疏，关闭补充后保持完整普通阅读体验。禁止自动播放解释、频繁弹窗或整页彩色划线。

### 打开一本书

1. 本地导入、计算版本并展示可读部分，不等待模型。
2. 有 Key 且开启补充时，生成“阅读前先知道”：本章要解决什么、与上下文的关系、最需要的少量前置知识。只处理实际读取范围，显示覆盖页码/小节。
3. 当前小节检测疑难点并预生成少量最可能阻塞阅读的解释。读者可以查看所有候选，但系统不自动把一章扩成一本书。
4. 后台工作可暂停、取消，有明确的 token/费用预算。用户选区请求始终优先。

概览分两类：只基于目录和抽样的“结构预览”，以及基于已覆盖章节的“内容概览”。禁止把前者标为已理解全文。

### 划词划句

选中后出现“解释”入口。默认结合所在段落、章节目标和已学内容解释。面板可继续选择“为什么”“从更基础讲”“给个例子”“核查/深搜”，但不要求用户先学会提问。

首屏先给能解除当前阻塞的答案；下面展开完整教学内容。短层不是空泛摘要，应至少回答这里的含义或省略的关键一步。层级来自同一解释包，展开已缓存内容不重新计费。

如果词义不明，优先使用原文语境消歧；证据仍不足时，直接说明可能的两种含义，只问一个真正影响答案的问题。

### 解释套娃

解释正文与原文使用同一个选区系统。选中解释中的词句，可生成子解释，面包屑显示“教材 §2 → 方差相加 → 协方差”。

保存每层滚动位置、选区和父节点。返回父解释时定位到原来的句子，不重新生成父内容。节点可收藏、导出、分支追问；用户可继续深入，不以固定层数强行截止。

自动追溯只展开有限层必要前置。当连续追问集中在同一个基础概念，提示“先补一段基础会更顺畅”，给可跳过的短课；不会自动替用户开启大批生成任务。相同概念的循环依赖要识别并改用具体例子或既有解释，而非无限调用。

## 4. 解释应补哪些缺口

每个片段先判断问题类型，而非统一套八段模板。

| 缺口 | 典型困惑 | 应补内容 |
| --- | --- | --- |
| 名词与符号 | “它指什么？这个字母怎么突然出现？” | 语境内含义、对象类型、符号约定、一个实例 |
| 动机与用途 | “为什么引入它？” | 本节正在解决的任务、它让哪一步变得可做 |
| 前置知识 | “解释里的另一个词我也不懂” | 最短必要前置路径、就地小解释或可点开的入口 |
| 推理跳步 | “怎么就显然了？” | 假设、关键中间步骤、使用的规则或定理 |
| 证据缺失 | “凭什么相信这句话？” | 观察/实验/史料/证明，以及证据的限制 |
| 边界与量词 | “总是这样吗？” | 成立条件、例外、反例、必要与充分的区分 |
| 结构关系 | “这段与前一节有什么关系？” | 承上启下、正在完成的子目标、之后如何使用 |
| 易混概念 | “这个和另一个有什么区别？” | 同一个例子中的对照、差异导致的结果 |
| 图表与公式 | “图在表达什么？” | 轴、图例、单位、符号、可见关系与解释性推断 |

## 5. 内容合同

解释的教学目标是让读者读回原句时，知道每个关键部分在说什么、为什么有依据、在哪里能用。

应按需要包含以下功能，允许合并、略去不相关项，标题用读者的语言：

1. **这句话在这里说什么**：引用小范围原句并做语境内解释。
2. **为什么这里要说它**：指出当前问题或论证中的作用；没有明确用途时不强行编造。
3. **先补哪一点**：只补真正必需的前置概念，在首次使用处解释；不要用新术语串替换旧术语串。
4. **为什么成立**：提供可检查的推导、证据链或解释依据。类比不能冒充证明。
5. **看一个具体例子**：给足数字、单位或语境；演示关键步骤及检验方法。
6. **什么时候不能这么说**：必要条件、常见误解、反例或竞争解释。
7. **回到原文**：指出原文省略了什么，现在如何重新读它。
8. **试一下是否会用**：一个可选的小任务，答案折叠；答错后给对应补救入口。

“从零”指从该读者能接受的起点搭桥，不是对所有话题回溯至最基础公理。若起点未知，先提供可读的小例子，并明确可继续解释的关键前置。不得假装已经诊断了用户所有知识。

简短默认层可建议约 150–350 中文字，完整层按需要展开；这些是显示预算，不是内容评分标准。复杂推导应保留足够篇幅，减少一次展示量而非删去关键条件。

### 学科适配

- 数学、逻辑与算法：定义、量词、条件、推导、证明与反例；算例不能证明一般命题。
- 经验科学：现象、模型、测量、实验依据、误差及适用尺度；不把模型当现实本身。
- 历史与文学：作者、时代、材料和解释；区分直接证据、推断与有依据的分歧。
- 社会科学与决策：描述、因果和价值判断分开，说明制度、样本、地区与时间。
- 实践技能：提供步骤、观察标准和反馈，明确文字无法代替现场操作的部分。

不强迫每个概念都有“历史上先失败再发明”的故事。可以用教学构造情境，但必须标明它不是历史事实。

## 6. 内容样例：解释一句“显然”

原句：**“由于 X 与 Y 独立，显然 Var(X+Y)=Var(X)+Var(Y)。”**

假设读者了解四则运算和平均数，不了解方差、期望、协方差。以下为设计样例，非真实模型输出。

### 默认显示层

这里的“方差”描述结果围绕平均值的波动：先看每次结果偏离平均值多少，把偏差平方，再按各结果出现的概率求平均。

原句说的是：当 X、Y 独立且方差有限时，两者相加的方差等于各自的方差之和。独立表示知道 X 的结果不会改变 Y 各种结果的概率。它使相加时多出来的一项“共同偏离的平均乘积”变成 0，这就是作者省略的一步。下面可以看到这项从哪里来。

### 展开：先用一个例子看懂

抛两枚互相独立的公平硬币：正面记 1，反面记 0。第一枚的数是 X，第二枚是 Y。

X 一半是 0、一半是 1，平均是 0.5。无论哪种结果，它与平均值的差都是 ±0.5，平方都是 0.25，所以 Var(X)=0.25。Y 同理。

X+Y 的结果是 0、1、2，概率分别是 1/4、1/2、1/4，平均是 1。对应的平方偏差是 1、0、1，因此方差是 1/4×1+1/2×0+1/4×1=0.5，恰好等于 0.25+0.25。

这个例子展示结论如何工作；一般情况还需要下面的推导。

### 展开：把省略的一步补出来

用 E[Z] 表示“按概率加权得到的 Z 的平均值”，也叫期望。把 X 的偏差写成 A=X−E[X]，Y 的偏差写成 B=Y−E[Y]。偏差本身的平均值为 0，因此 E[A]=E[B]=0。

X+Y 的平均值是 E[X]+E[Y]，所以它的偏差是 A+B。把这个偏差平方，有 (A+B)²=A²+2AB+B²。

再对三项求平均：

`Var(X+Y) = E[A²] + 2E[AB] + E[B²]`

第一项和最后一项就是 Var(X)、Var(Y)。中间的 E[AB] 叫协方差：衡量两个量是否倾向于一起高于或低于各自平均值；不能单凭协方差就判断全部依赖关系。

独立使 E[AB]=E[A]E[B]=0。这一步用到了“独立时乘积的平均等于平均的乘积”：对于有限种可能的情况，每一对结果的联合概率可以拆成两边概率的乘积，求和也就能分开。连续情形使用相应积分规则。这个规则本身也可以继续划选解释。

因此中间项消失，得到原式。这里要求 X、Y 的二阶矩有限，避免上述平均和展开出现未定义的运算。

### 展开：不独立时会怎样

如果 Y=X，也就是把同一枚硬币的结果算两次，那么 X+Y=2X，结果只有 0 或 2，各占一半，平均是 1，方差是 1。它不是 0.25+0.25。

也别倒过来误读：方差能相加，并不一定说明独立。对方差有限的变量，这个等式恰好需要协方差为 0；独立是保证这一点的充分条件。

### 回到原文

作者把“展开平方 → 多出交叉项 → 独立使交叉项平均为 0”压缩成了“显然”。下次看到“独立，所以方差相加”，可以先检查是否仍有独立条件，以及相关方差是否有限。

### 可选小检查

两台设备的误差分别是 X、Y，方差为 4 和 9，且二者独立、方差有限。相加误差的方差是多少？如果把第一台的误差读数原样复制为 Y，方差还能直接相加吗？

折叠答案：第一问 13。第二问不能沿用独立假设；Y=X 时 Var(X+Y)=4Var(X)=16。复制的情境替换了 Y 的定义，不能继续沿用前一问 Y 的方差 9。

### 此样例的验收重点

解释应能帮助读者找出被省略的交叉项，辨别独立与零协方差，并返回原句。是否喜欢文风不是充分证据。样例中的 E、联合概率等仍应提供递归解释入口，不能假定读到定义就已掌握。

## 7. 范围与非目标

首个完整版本覆盖 PDF、扫描 PDF、Markdown、TXT、DOCX、PPTX，支持划选、概览、预补充、解释套娃、本地检索缓存和按需联网深搜。

按里程碑逐步实现是控制风险的方法，不得把后续阶段未完成的需求称为已交付。首个可测试闭环可以先支持 Markdown/TXT 与数字 PDF，但项目完成需覆盖上述格式。

首版不做账号社区、多人云同步、自动上传全盘、Office 编辑、幻灯片动画播放或全书自动重写。可导出解释与引用，保障用户积累可迁移。

## 8. 质量指标

主要指标是实际阅读任务中的理解与迁移，不是解释数量、字数、停留时长或模型自评分。记录原句复述、条件辨别、变式题表现，以及关闭解释后继续阅读是否顺畅。

辅助指标包括返回原文率、重复卡住的概念、无需提示完成任务的比例。重复追问既可能意味着兴趣也可能意味着解释失败，不能单独当正面指标。

与基础方案对比：只看原文、简单问答提示词、完整补充流程。使用等难度材料或交叉安排，避免同一题重复作答带来的练习效应。小样本试用只能发现问题，不能证明普遍学习效果。
